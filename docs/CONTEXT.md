# ภาษาของ HAMS สำหรับแผนส่งมอบบน Server ลูกค้า

คำศัพท์ธุรกิจที่ใช้ในแผนส่งมอบนี้อ้างอิง [Business Domain ของ HAMS](../backend/CONTEXT.md#business-domain) และขยายความตามข้อตกลงในการสัมภาษณ์ แผนสถาปัตยกรรมและวิธีติดตั้งอยู่ใน [แผน refactor](plans/customer-server-refactor.md)

## Language

**Asset Image (รูปครุภัณฑ์)**:
รูปหลักที่ผูกกับทะเบียนครุภัณฑ์เพื่อช่วยระบุเครื่อง ผู้มีลิงก์ที่เข้าถึงเครือข่ายของระบบได้สามารถอ่านรูปได้โดยไม่ต้องล็อกอิน HAMS การเปิดอ่านจากลิงก์ไม่ได้หมายความว่าต้องเผยแพร่รูปบนอินเทอร์เน็ต
_Avoid_: รูปประจำบุคลากร, รูปสาธารณะบนอินเทอร์เน็ต

**Employee Photo (รูปประจำบุคลากร)**:
รูปที่ผูกกับบัญชีบุคลากรเพื่อระบุตัวบุคคลภายใน HAMS และอยู่ภายใต้เงื่อนไขการเข้าถึงของระบบ รูปประเภทนี้ไม่ได้มีสถานะเปิดอ่านถาวรสำหรับผู้ถือ URL ทั่วไป
_Avoid_: รูปครุภัณฑ์, รูปโปรไฟล์สาธารณะ

**Expense History (รายจ่ายย้อนหลัง)**:
ข้อมูลรายจ่ายจริงที่เกิดขึ้นแล้วใน HAMS ประกอบด้วยค่าใช้จ่ายซ่อมและการจัดหาครุภัณฑ์ในช่วงเวลาที่แสดง
_Avoid_: ผลพยากรณ์รายจ่าย, งบประมาณที่อนุมัติ

**Expense Forecast (ผลพยากรณ์รายจ่าย)**:
ค่าประมาณรายจ่ายในอนาคตที่ใช้ประกอบการวางแผนของโรงพยาบาล การไม่มีผลพยากรณ์หมายถึงไม่มีค่าประมาณให้ใช้ ไม่ได้หมายความว่ารายจ่ายอนาคตเป็นศูนย์
_Avoid_: รายจ่ายจริง, งบประมาณที่อนุมัติ, ศูนย์บาทเมื่อไม่มีผลพยากรณ์

**Asset Lifespan Analysis (การวิเคราะห์อายุครุภัณฑ์)**:
ข้อมูลสรุปอายุครุภัณฑ์เมื่อเทียบกับอายุการใช้งานที่กำหนด เพื่อประกอบการติดตามเครื่องที่ใกล้หรือเกินอายุใช้งาน เป็นข้อมูลคนละประเภทกับผลพยากรณ์รายจ่าย
_Avoid_: ผลพยากรณ์รายจ่าย
