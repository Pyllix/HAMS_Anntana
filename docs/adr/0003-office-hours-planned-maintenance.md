# รองรับการดูแลระบบตามนัดนอกเวลาราชการ

ผู้ใช้ยืนยันว่าการใช้งาน HAMS เป็นเวลาราชการตามปกติและไม่ได้ต้องให้บริการตลอด 24 ชั่วโมง จึงเลือกให้การติดตั้งบน server ลูกค้ารองรับช่วงพักใช้งานตามนัดสำหรับอัปเดตหรือดูแลข้อมูลนอกเวลางาน แทนการเพิ่มสถาปัตยกรรมที่ต้องรับรายการต่อเนื่องระหว่างอัปเดตในงานรอบนี้ เพื่อลดความซับซ้อนให้เหมาะกับการเริ่มติดตั้งบน server เดียว

ต้องนัดช่วงจริง รอรายการที่กำลังบันทึกให้เสร็จ รักษาฐานข้อมูลและรูปให้สอดคล้องกัน และตรวจความพร้อมก่อนเปิดใช้งานอีกครั้ง ระยะพักสูงสุดและเป้าหมายการกู้คืนยังต้องตกลงกับลูกค้าก่อน production; การเลือกนี้ไม่ได้เป็นการรับรอง availability หรืออนุญาตให้หยุดระบบโดยไม่นัดหมาย ส่วนเครื่องมือสำรองเป็นของ IT ตามคำตอบ `8B` ดูคำตอบ `9A` และขั้นตอนอัปเดต/ย้อนกลับใน [แผน refactor](../plans/customer-server-refactor.md)
