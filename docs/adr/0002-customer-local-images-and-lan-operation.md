# เก็บรูปในเครื่องลูกค้าและให้งานหลักใช้งานผ่าน LAN

ผู้ใช้เลือก filesystem บน server ลูกค้าที่ตั้งตำแหน่งโฟลเดอร์ข้อมูลได้และแยกจากโค้ด แทนการเพิ่มระบบจัดเก็บไฟล์แยก เพื่อลดบริการที่ต้องติดตั้งและดูแลสำหรับการเริ่มใช้บน server เดียว พร้อมกำหนดให้งานทะเบียน ยืมคืน ซ่อม และรูปทำงานผ่าน LAN ได้หลังติดตั้งและเปิดบัญชี แม้ขาดอินเทอร์เน็ตสาธารณะ การสำรองข้อมูลจึงต้องครอบคลุมทั้งฐานข้อมูลและไฟล์รูป

คงรูปครุภัณฑ์ที่ผู้มีลิงก์และเข้าถึงเครือข่ายถึงอ่านได้ และรูปประจำบุคลากรที่ต้องผ่านการอนุญาตของ HAMS การเปิดอ่านจากลิงก์ไม่ได้กำหนดให้เปิด server สู่อินเทอร์เน็ต; SMTP ต้องเข้าถึงปลายทางที่ตั้งไว้และ Gemini ต้องมีอินเทอร์เน็ตเมื่อเปิดฟีเจอร์ โดยยังคง Cloudinary สำหรับการติดตั้งรูปแบบ cloud ตาม [ADR 0001](0001-support-cloud-and-customer-server.md) ดูคำตอบ `5A, 6A, 7A` ใน [แผน refactor](../plans/customer-server-refactor.md)

การยืนยันเพิ่มเติมจากคำตอบ `8B`: ทีมพัฒนาส่งมอบคู่มือสำรอง/กู้คืนและเกณฑ์ตรวจความถูกต้อง ส่วน IT ลูกค้าจัดหาเครื่องมือเอง งานรอบนี้ไม่รวมการพัฒนาเครื่องมือสำรองหรือกู้คืนใหม่

คำตอบ `9A` ยืนยันว่าการใช้งานเป็นเวลาราชการตามปกติและไม่ต้องให้บริการตลอด 24 ชั่วโมง จึงยอมรับช่วงพักใช้งานนอกเวลาราชการตามนัดสำหรับดูแล/อัปเดต แผนรอบนี้รองรับวิธีดังกล่าวแทนการเพิ่มสถาปัตยกรรมอัปเดตโดยรับรายการต่อเนื่อง โดยระยะพักจริงและขั้นตอนกลับมาเปิดระบบต้องตกลงก่อนดำเนินการ
