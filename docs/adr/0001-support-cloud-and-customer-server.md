# รองรับ Cloud และ Server ลูกค้าจากโค้ด HAMS ชุดเดียว

ผู้ใช้เลือกให้คงการติดตั้งบน cloud เดิมและเพิ่มการติดตั้งบน server ลูกค้า โดยเลือกบริการที่เกี่ยวข้องผ่านค่าตั้งของแต่ละการติดตั้ง เพื่อให้ยังพัฒนาและสาธิตบนระบบเดิมได้ระหว่างเตรียมระบบลูกค้า ทางเลือกที่พิจารณาคือถอดการรองรับ cloud แล้วรองรับเฉพาะเครื่องลูกค้า แต่ยอมรับภาระดูแลและตรวจสอบสองรูปแบบเพื่อรักษาความสามารถทั้งสองไว้

ข้อตกลงนี้ให้คง Cloudinary สำหรับรูปแบบ cloud และออกแบบที่เก็บรูปของลูกค้าเพิ่มเติม รายละเอียดที่เก็บรูปและสิทธิ์อ่านยังรอการตัดสินใจ ไม่ได้กำหนดให้สลับ provider ของข้อมูล production ที่มีอยู่โดยอัตโนมัติ ดูคำตอบ `1A` และขอบเขตเริ่ม production ใหม่ใน [แผน refactor](../plans/customer-server-refactor.md)
