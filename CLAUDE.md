# CLAUDE.md

## Backend is off-limits

Do NOT create, edit, delete, rename, or move any file under `backend/`.
This includes formatting, lint fixes, dependency updates, and running
commands that write to `backend/` (e.g. installs, migrations, code generators).

- Reading files in `backend/` for context (API shapes, routes, types) is fine.
- If a task seems to need a backend change, stop and tell the user what change
  is needed instead of making it.
- Work only in `front-end/` (and repo-root docs when asked).
