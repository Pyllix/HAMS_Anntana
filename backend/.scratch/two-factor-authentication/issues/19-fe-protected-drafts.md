# 19 — FE: ปกป้องฟอร์มค้างเมื่อ Session หมดหรือสลับบัญชี

**What to build:** งานที่ยังไม่บันทึกไม่ถูกส่งด้วย Session ที่หมดอายุหรือเปิดให้บัญชีอื่นเห็น และเจ้าของเดิมกลับมาทำต่อได้ในแท็บเดิม

**Blocked by:** 18 — FE: เตือนก่อน Session หมดและให้ใช้งานต่อ

**Owner / change boundary:** Frontend protected-content overlay และ draft lifecycle; ประสานเจ้าของหน้าฟอร์มแต่ไม่แก้ service transport ของ ticket 13–15

**Status:** ready-for-agent

- [ ] เมื่อ Session หมดอายุ ซ่อนข้อมูลที่ป้องกันและหยุดคำขอแก้ข้อมูลทันทีจน Login ใหม่
- [ ] เก็บข้อมูลฟอร์มที่ยังไม่บันทึกไว้เฉพาะแท็บที่ยังเปิดและคืนให้เฉพาะบัญชีเดิมหลัง Login
- [ ] หากบัญชีอื่น Login ต้องล้าง draft และไม่แสดงฟอร์ม/ข้อมูลของบัญชีเดิม
- [ ] ตรวจและปรับ draft storage เดิมไม่ให้ข้อมูลข้ามบัญชี แม้มี localStorage สำหรับข้อมูลที่ไม่ใช่ Session Token
- [ ] เตือนก่อน Refresh/ปิดแท็บตามความสามารถ Browser และไม่สัญญาว่ากู้ draft หลังปิดแท็บได้
- [ ] ทดสอบฟอร์มสำคัญอย่างน้อยหนึ่งรายการต่อกลุ่มงานหลัก รวมทั้งการสลับบัญชีและการหมด Session ระหว่างกดบันทึก
